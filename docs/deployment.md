# Deployment

The site is a static website and works directly with GitHub Pages.

1. Push the repository to the `main` branch.
2. In GitHub, open **Settings > Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for deployment.

FormSubmit requires the destination email to be activated through its verification email on first submission.
